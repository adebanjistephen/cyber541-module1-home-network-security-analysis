# CYBR 541 - Module 1
## Home Network Security Assessment and Attack Surface Analysis

This lab was completed as part of **CYBR 541 – Network Security** at **Northern Illinois University**.

## Objective

The objective of this lab was to understand the security posture of a simulated home network by performing:

- Network verification
- Reachability analysis
- Trust boundary identification
- Attack surface assessment
- IoT security analysis
- Lateral movement analysis
- Availability and impact assessment
- Physical vs Logical topology comparison
- Network segmentation discussion

## Key Learning Outcomes

- Identified critical trust boundaries within a home network.
- Evaluated attack surfaces across user devices, IoT devices, routers, and servers.
- Demonstrated network reachability using ICMP and ARP.
- Analyzed lateral movement opportunities resulting from flat network architecture.
- Identified single points of failure affecting network availability.
- Explained why network segmentation improves cyber resilience.
